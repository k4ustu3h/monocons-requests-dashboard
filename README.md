# Monocons Requests Dashboard
Browse, sort, and filter Monocons icon requests. Plan contributions, view stats, and more.

Please report any issues via the Monocons repository.

[Dashboard](https://monoconsrequests.vercel.app/) • [Monocons](https://github.com/k4ustu3h/monocons-android)
